# 1,000문항 구성과 내부 검토 범위

기존 `CONF-001`–`CONF-060` 60개를 그대로 보존한다.
추가 `CONF-N01-001`–`CONF-N20-047` 940개는 각각 숫자 조건 변형으로 표시한다.
기출·복원은 0, 자체 제작 1,000, 숫자 변형 940, 독립 개념/계산 유형은 80이다.

각 유형에는 47개 서로 다른 입력 조합이 있다. 질량·배합·농도·가격·크기 등의
제시 조건을 달리하며 결과만 바꾸거나 보기 순서만 바꾼 문항을 추가하지 않는다.
동일 산식의 47개를 의미상 독립 개념이라고 주장하지 않는다.
재료 349 / 제조 584 / 위생 67이라는 배분은 학습용 구성이지 공식 출제 비율이 아니다.

| family | 단원 | 계산 정의와 내부 검토 항목 |
| --- | --- | --- |
| CONF-N01 | 제조·배합 백분율 | 밀가루 기준 질량 × 비율/100; 베이커스 퍼센트의 분모 명시 |
| CONF-N02 | 제조·배합 확대 | 기존 재료 질량 × 새 밀가루/기존 밀가루; 배합비 유지 명시 |
| CONF-N03 | 제조·총 배합량 | 밀가루 × 모든 베이커스 비율 합/100; 밀가루 100% 포함 |
| CONF-N04 | 제조·굽기 손실량 | 초기 질량 × (1−손실률/100); 손실 기준은 초기 질량 |
| CONF-N05 | 제조·손실률 | 감소 질량/초기 질량 × 100; 최종 질량을 분모로 쓰지 않음 |
| CONF-N06 | 제조·분할 개수 | 총 반죽/개당 질량의 버림; 남은 반죽으로 정량 제품을 만들지 않음 |
| CONF-N07 | 제조·개당 반죽량 | 총 반죽/분할 개수; 손실 없는 동일 질량 분할 |
| CONF-N08 | 재료·시럽 농도 | 설탕/(설탕+물) × 100; 용액 전체 기준 질량% |
| CONF-N09 | 재료·시럽 희석 | 시럽 질량 × (초기 농도/목표 농도−1); 설탕 질량 보존 |
| CONF-N10 | 재료·지방 함량 혼합 | 지방 질량 합/전체 질량 × 100; 가중 평균 |
| CONF-N11 | 재료·단백질 함량 혼합 | 단백질 질량 합/전체 가루 질량 × 100; 단순 평균과 구별 |
| CONF-N12 | 재료·원료 수분량 | 원료 질량 × 수분 질량%/100; 비율은 문제에서 제공 |
| CONF-N13 | 재료·고형분량 | 혼합물 질량 × (100−수분 질량%)/100 |
| CONF-N14 | 재료·주어진 계수의 열량 | 탄수화물×4 + 단백질×4 + 지방×9; 계수와 성분을 문제에서 한정 |
| CONF-N15 | 제조·원료 사용 원가 | kg당 가격 × 사용 g/1,000; g/kg 단위 변환 |
| CONF-N16 | 제조·개당 재료 원가 | 총 재료 원가/판매 가능한 개수; 다른 비용 제외 |
| CONF-N17 | 위생·이력 재고 계산 | 시작 재고−오전 사용−오후 사용; 입고·폐기·손실 없음 |
| CONF-N18 | 제조·팬 면적 배합 조정 | 기존 질량 × 새 지름²/기존 지름²; 두께·밀도 동일 조건 |
| CONF-N19 | 제조·반죽 비중 | 같은 부피의 반죽 순질량/물 순질량; 용기 질량 제외, 무차원 |
| CONF-N20 | 제조·생산 회차 올림 | 생산 개수/회당 용량의 올림; 마지막 미충전 회차 허용 |

각 유형의 문장과 위 공식·분모·단위를 내부 검토했고, 940개 조건은 별도
TypeScript 식으로 재계산한다. 생성은 Python Decimal의 ROUND_HALF_UP,
검증은 JS 수치와 오차 보정 반올림을 사용한다. 개수는 명시한 버림·올림으로 구한다.
보기 4개는 동일 단위의 서로 다른 비음수 값이며 반올림 후 정답이 하나인지 검사한다.
답안 위치와 보기의 수치 순위도 조건별로 바꿔 위치만으로 풀리지 않게 한다.
해설에는 주어진 조건·식·대입·결과·단위 및 반올림 정책을 제공한다.

검토자는 AI이며 외부 전문가 검수는 아니다. 계산 검사가 해설 전체의 외부 사실 검증을
대신하지 않는다. 공식 출제기준·교재와 대조하지 못했으며 공식 시험 분포의 적합성을
보장하지 않는다. 이 상태는 앱 문제은행과 README에 함께 표시한다.

재생성: `python3 scripts/prepare.py`.
확인: `npm test`의 `tests/calculations.test.ts`, `tests/model.test.ts`.
현재 데이터 SHA256과 유형별 수는 `bank-audit.json`에 기록했다.
